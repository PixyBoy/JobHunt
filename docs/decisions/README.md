# Architecture Decision Records

Use ADRs only for decisions that are expensive to reverse or affect multiple parts of the system.

File naming:

`NNNN-short-decision-title.md`

Minimum structure:

```markdown
# Decision title

## Status
Accepted | Superseded | Deprecated

## Context
Why a decision is required.

## Decision
What was chosen.

## Consequences
Important trade-offs and follow-up work.
```

Do not create ADRs for routine implementation details.
